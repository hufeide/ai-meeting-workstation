# Demo audio boundary

The distributable fallback is generated by the Apache-2.0 Kokoro-82M model from an original fictional Chinese script. See `PROVENANCE.md` for details:

```text
chengyuan-tech-fallback-open-kokoro.wav
```

`chengyuan-tech-fallback.wav` is reserved for an authorized local human-recording test. `chengyuan-tech-fallback.system-tts-backup-2026-08-04.wav` was made with an Apple system voice and is local-only under Apple's macOS voice terms. Both are ignored by Git and must not be uploaded or distributed.
